# Human-in-the-Loop Review Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A persisted approval queue: flagged answers (low confidence, rescue/verify path, backend error — or every answer when `ENABLE_HUMAN_REVIEW=on`) enter the queue instead of the conversation; an officer approves/edits/rejects with full citations; approved answers then land in the conversation history.

**Architecture:** SQLite `review_queue` table + repo helpers; queue insertion inside the agent routes (execute + stream), replacing the auto assistant-persist for flagged turns; `/api/review/*` endpoints; Next.js page `/review-hub` registered in the Plan 1 launchpad registry.

**Tech Stack:** FastAPI, SQLite (repo pattern `src/core/database.py`), Next.js 14.

**Spec:** Launchpad vision item 5. Decision: queueing policy = `ENABLE_HUMAN_REVIEW` on → everything queues; off → auto-queue low-confidence / verification-failed / error turns.

### Task 2: Queue-insertion policy in agent routes

**Files:**
- Modify: `src/api/routes/agents.py`

**Interfaces (consumed by Task 3):** review rows have keys `id, conversation_id, query, draft_answer, agent_type, citations, trace, confidence, reason, status, edited_answer, created_at, updated_at`. Response metadata gain: `metadata["review"] = {"id": int, "status": "pending"}` for queued turns.

- [ ] **Step 1:** Import `settings` (`from config.settings import settings`) and add:

```python
def _should_queue(response, conv_used: bool) -> tuple[bool, str]:
    meta = response.metadata or {}
    trace = meta.get("trace") or []
    rescue = any(t.get("node") in ("verify", "wide_search") for t in trace)
    low_conf = response.confidence_score < 0.5
    if settings.enable_human_review:
        return (True, "human review enabled")
    if meta.get("error") or rescue or low_conf:
        return (True, f"error={bool(meta.get('error'))} rescue={rescue} low_confidence={low_conf}")
    return (False, "")
```

- [ ] **Step 2:** In `execute_agent`: after building `result`, call `queue, reason = _should_queue(result, conv is not None)`; if queued → `item = db.add_review_item(conv["id"] if conv else None, query.query, result.result, agent_type=result.agent_type, citations=result.citations, trace=result.metadata.get("trace"), confidence=result.confidence_score, reason=reason)`; do NOT `_persist_turn`; merge `result.metadata["review"] = {"id": item["id"], "status": "pending"}`. Not queued → persist as today.
- [ ] **Step 3:** Same policy in `execute_agent_stream`'s generator: user message already saved before streaming; after the final `done` event, queue (skip assistant save) or persist as today; attach `metadata["review"]` into the `done` payload's response metadata (mutate before yield or clone — do not double-send).
- [ ] **Step 4:** Tests (same file as Task 1): monkeypatch `get_router_agent` (module-level in `agents.py`) to return a fake router whose `invoke` returns `AgentResponse(agent_type="due_diligence", result='{"summary":"x"}', citations=[], confidence_score=0.4, metadata={"trace":[{"node":"verify","ms":1}]})`; with a created conversation and `settings.enable_human_review=False` → `POST /api/agents/execute` returns `metadata.review.id`, conversation has user message only (1 msg), review row pending with reason containing `low_confidence`. High-confidence fake (0.9, no rescue) → no review row, conversation has 2 messages. Then monkeypatch `settings.enable_human_review=True` → queues even high-confidence.
